# False Opposite-Face Rules

| ID | 오류 | 설명 |
|---|---|---|
| `FF-01` | MIRROR_COMPLETION | Visible View의 거울상으로 반대면 생성 |
| `FF-02` | TRANSCRIPTION_AS_FACSIMILE | 전사를 실물자형으로 취급 |
| `FF-03` | LANDING_PAGE_AS_STROKE_FACE | 페이지 존재를 필순관측으로 취급 |
| `FF-04` | UNICODE_AS_SEMANTIC_FACE | 코드포인트를 의미권위로 확장 |
| `FF-05` | CHRONOLOGY_AS_CAUSAL_FACE | 순서를 인과로 확장 |
| `FF-06` | SINGLE_SEAT_AS_OPPOSITE_VIEW | 한 Seat 복제 |
| `FF-07` | CONFLICT_ERASURE | 충돌 View 삭제 |
| `FF-08` | ABSTRACT_SHEET_AS_REALITY | Analysis Sheet 후보의 Reality 승격 |


## Test Registry Use

이 문서는 `01_Analysis_Method/06_Rendering_Analysis/FALSE_OPPOSITE_FACE_RULES.md`의 규칙을
R07/R09 검산항목으로 다시 적용한 시험 Registry다.

- 규칙문서: 무엇을 금지하는가
- 시험문서: 어떤 실패입력으로 금지규칙을 검산했는가

두 문서는 같은 표를 공유할 수 있으나 역할과 Identity는 다르다.
