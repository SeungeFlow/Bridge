## 9. Execution-State Codes

| 상태 | 의미 |
|---|---|

| `NOT_APPLICABLE` | 문제유형과 해당 Method 축이 관계없음 |

### 9.1 Source Gap과 Method Gap

```yaml
BLOCKED_SOURCE:
  example:
    - 필순 이미지 없음
    - 판본 자형 좌표 없음
    - Stable Entry 없음

BLOCKED_METHOD:
  example:
    - 복수 특이점 중 주특이점 선택규칙 없음
    - Cycle Closure 기준 미완성
    - Center 승격규칙 미완성
    - 독립축 정량거리 없음
```

Source를 더 찾으면 해결되는 문제와 분석규칙 자체가 미완성인 문제를 섞지 않는다.

## 10. Mandatory Order Rules

| ID | 규칙 | 설명 |
|---|---|---|
| `OR-01` | Identity before Relation | 객체 Identity를 고정하기 전에 관계·의미·계보를 결합하지 않는다. |
| `OR-02` | Reality before Abstraction | Reality/Source 상태를 먼저 결속한 뒤 추상구조를 형성한다. |
| `OR-03` | Frame before Difference | 기준틀·관측방향을 고정한 뒤 차이·역구성을 수행한다. |
| `OR-04` | Independent Views before Relation | 각 관점을 독립분석·Evidence 잠금한 뒤 관계검산한다. |
| `OR-05` | Structure before Semantics | 구조와 의미를 독립 추출한 뒤 마지막에 대조한다. |
| `OR-06` | Snapshots before Causality | 시간순서·분기·겹침을 보존한 뒤에도 인과는 별도 Gate로 남긴다. |
| `OR-07` | Path before Transition | Start/End와 Body/Function을 배치한 뒤 전환후보를 찾는다. |
| `OR-08` | Transition before Center | 복수 전환후보와 Cycle Closure를 검산한 뒤 Center를 탐색한다. |
| `OR-09` | Correction after Original Preservation | 원래관찰을 보존한 뒤 Append-only Correction을 붙인다. |
| `OR-10` | Minimum after Full Candidate | 초기 후보조합을 형성한 뒤 제거시험으로 최소충분 조합을 정한다. |

### 10.1 Universal runtime order

```text
Identity
→ Reality/Source
→ Required Frame
→ Independent Atom/View Execution
→ Evidence Lock
→ Relation
→ Candidate Interpretation
→ Counterexample/Correction
→ Stop or Promotion
```

Center·의미·인과·역사계보는 각각의 선행 Gate가 닫힌 뒤에만 열린다.

## 11. Ablation and Minimality Rules

| ID | 시험 | 판정 |
|---|---|---|
| `AB-01` | Atom removal | Atom을 제거했을 때 typed result가 같으면 중복 또는 보조 Atom으로 낮춘다. |
| `AB-02` | Axis removal | 축을 제거했을 때 대상층이 사라지지 않으면 새 독립축이 아니다. |
| `AB-03` | View removal | 관점을 제거해도 질문의 답유형이 같으면 그 관점은 최소조합에서 제외한다. |
| `AB-04` | Order swap | 독립 View 잠금 이후 결과가 순서에 따라 바뀌면 조합규칙이 불안정하다. |
| `AB-05` | Evidence downgrade | 권위가 낮은 Source로 바꿨을 때 결론이 유지되는지보다 Evidence 상태가 정확히 낮아지는지 본다. |
| `AB-06` | Counterexample injection | 반례를 투입했을 때 조합이 깨지면 범위를 줄이거나 Failure Boundary를 명시한다. |
| `AB-07` | Missing-view test | 누락면을 제거상태로 두고도 허위 전체복원이 생기지 않는지 검산한다. |
| `AB-08` | Same-axis duplication | 같은 축을 다른 이름으로 반복한 Method가 분석차원을 부풀리는지 검산한다. |

## 12. Minimum-View Rule

```yaml
ONE_VIEW:
  use_when:
    - 결정적 기계연산
    - 단순 현재상태
    - 단일 Source의 보고범위 보존

TWO_VIEWS:
  use_when:
    - 표면과 Identity
    - Identity와 환경
    - 순서와 구조차이
    - Reality와 추상구조

THREE_VIEWS:
  use_when:
    - 현재·Identity·계보
    - Result·Authority·Formation
    - 공통장·Identity·자기시계

THREE_PLUS_OR_CLOSED_CYCLE:
  use_when:
    - Center·Cycle Closure
```

관점 수는 대상의 겉보기 복잡도가 아니라 질문에 필요한 독립관계층 수로 정한다.
