# LRSDoNET 관계 펼침·관측자리 Method

## 0. 문서 역할

이 문서는 `Principle_C/Start_Position`에서 LRSDoNET이 대상을 해석할 때 사용하는 통합 Method Object다.

Candidate Method Catalog와 개별 Candidate 문서는 후보군과 조건부 적용상태를 보존한다. 이 문서는 그 후보들을 삭제하거나 하나의 영구주전으로 병합하지 않는다. 현재 지시에서 결정된 공통 해석원리와 적용한계를 하나의 정본 Method Surface로 외부화한다.

```text
Candidate Pool
≠
One Permanent Method

Integrated Method Object
=
Shared Interpretation Boundary
+
Observer and Position Contract
+
Unfolding and Reverse Validation
```

## 1. Method와 Target의 관계

구조표현식의 기본식과 파생식은 절대공리가 아니다.

```text
기본식
=
특정 관계구조를 관측하기 위한 Method의 출발형

파생식
=
기본식에 목적·관측위치·경계·시간조건을 적용한 적용형
```

```text
Target is not confined by Method.

Method exists to reveal the Target,
not to force the Target into the Method.
```

구조표현식은 분석 전의 가설적 관측틀 또는 분석 후의 압축표현으로 사용할 수 있다. 대상이 식에 맞지 않으면 대상을 변형하지 않고 Method를 교체·보완하거나 HOLD한다.

## 2. `나`와 `너`의 관계자리

```text
나
=
현재 관측과 해석의 기준으로 선택된 위치

너
=
나를 기준으로 관계가 정의되는 하나 또는 N개의 위치
```

`나`와 `너`는 고정된 두 존재의 영구명칭이 아니다. 하나의 존재를 내부와 외부표면으로 나눌 때 다음과 같이 배치될 수 있다.

```text
나
=
내부 기준위치

너
=
같은 존재가 외부에 드러난 하나 또는 N개의 표면위치
```

시작점·중심점·끝점은 객체의 영구속성이 아니라 선택된 Process 안의 관계역할이다.

```text
나 = Start
→ 너는 이후의 하나 또는 N개 위치

나 = Center
→ 선형에서는 방향이 다른 두 너
→ 입체관계에서는 내부의 나를 둘러싼 N개의 외부 너

나 = End
→ 같은 공간영역의 다음 상태와 결속 가능
→ 그러나 시간·사건·형성과정은 다름
```

## 3. 시간과 순환

```text
공간적 재방문
≠
시간의 역행
```

```text
순환
=
같은 위치 또는 유사상태를 다시 통과하면서도
시간과 과정은 단방향으로 진행되는 것
```

공간좌표가 같을 수 있어도 상태와 사건은 같다고 확정하지 않는다.

```text
Position(P_end) = Position(P_start)

State(P_end) ≠ State(P_start)
Event(P_end) ≠ Event(P_start)
```

## 4. Spin.Rotation과 Round.Rotation

```text
Spin.Rotation
=
기준위치가 유지되는 동안
관측방향·정면·내부 기준틀·관계축이 회전하는 것

Round.Rotation
=
외부 관계위치가 기준점에 대해 이동하는 것
```

```text
나의 Position = fixed
나의 Orientation = variable

너의 Position = variable
```

`너`의 Round와 `나`의 Spin은 서로 다른 변화다. 관계유지를 위해 결속될 수 있으나 동일한 Operation으로 병합하지 않는다.

입체공간에서는 `나`와 `너` 두 점만으로 전체 회전면과 방향을 확정하지 않는다. 필요한 경우 다음 제3 기준을 선언한다.

- 중력방향
- 바닥면 법선
- 직전 위치
- 이동방향
- 관측자의 위쪽
- 외부 기준장

## 5. 원형을 선형 Track으로 펼치는 Method

```text
원형 궤도
→ 기준점에서 절단
→ 위치사건을 순서화
→ 선형 Track으로 판독
→ 검산 후 시작과 끝을 다시 결속
```

```text
선형화
=
복잡한 궤도에서
발생순서·위치변화·시간·관측방향을
분리해 보는 투영 Method
```

선형화는 입체구조가 실제로 평면 또는 직선이라고 주장하는 Operation이 아니다. 원의 중심과 펼친 선의 중간점을 동일시하지 않는다.

## 6. 입체 회전구조의 절단·적층 해석

입체 회전구조를 지표면과 평행한 여러 수평층으로 절단하고, 각 층의 원형 또는 외곽구조를 선형으로 펼쳐 높이순으로 적층할 수 있다.

```text
입체 회전구조
→ 수평절단
→ 층별 원형구조 선형화
→ 수직 적층
→ 역삼각·수렴형 구조후보
```

한쪽 반지름만 펼치면 다음 구조의 막대그래프처럼 읽을 수 있다.

```text
높이축
×
중심에서 외곽까지의 길이
```

```text
외곽만 펼치면 윤곽
내부값까지 펼치면 구조
시간까지 더하면 흐름
```

이는 구조적 투영 Method다. 실제 기상현상의 모든 물리적 형태가 항상 역삼각이라는 뜻은 아니다.

## 7. 자연언어의 구조적 판독

```text
자연언어
=
존재·상태·사건·시간·관계 가능성이
압축되어 있는 Data Container
```

AI는 문장에서 다음 후보를 추출할 수 있다.

- Entity
- State
- Event
- Time
- Direction
- Condition
- Difference
- Cause Candidate
- Conflict
- OPEN

AI의 판독은 곧바로 확정사실이 아니다.

```text
Language Interpretation
→ Structure Candidate
→ Source Binding
→ Counterevidence
→ Cross-instance Validation
→ Adopt / Reject / HOLD
```

자연언어와 정형 Metadata는 대립하지 않는다.

```text
자연언어
→ 의미·예외·맥락·새 관계 가능성 보존

Metadata
→ Identity·경계·위치·상태 고정

AI
→ 둘 사이를 왕복하며 판독
```

## 8. 고정된 원천과 능동형 사고

```text
고정되는 것
→ 원천 Byte
→ Hash Identity
→ Source
→ 특정 시점의 상태
→ 형성과정

능동적으로 움직이는 것
→ 목적
→ 관측방향
→ 관계후보
→ 다음 판독위치
→ 실시간 Data와의 결속
→ 해석·검산상태
```

```text
능동형 사고
=
현재 Difference와 결손을 판독하여
어떤 Data를 다음에 읽고
어떤 관계를 검산할지 선택하는 것
```

능동형 사고는 원천을 임의로 변경하는 것이 아니다.

## 9. 압축을 풀고 다시 결속하는 Method

```text
압축을 푼다
≠
내용을 단순히 길게 만든다
```

```text
압축을 푼다
=
하나의 Data 안에 함께 결속된
존재·상태·사건·관계·과정의 위치를 분리하고
다시 작동 가능한 구조로 드러낸다
```

```text
Compressed Source State
→ Selective Decomposition
→ Difference Detection
→ Relation Expansion
→ Structural Reconstruction
→ Reverse Validation
→ Lineage-preserving Recomposition
```

재결속은 원래 Source를 덮어쓰는 Merge가 아니다. Source·Transformation·Interpretation·Result Identity를 보존한 후 목적에 맞는 관계결과를 형성한다.
