# Execution Order

```text
Problem Type
→ Object Identity
→ Reality/Source
→ Required Frame
→ Independent View
→ Evidence Lock
→ Relation
→ Candidate Interpretation
→ Counterexample/Correction
→ Stop or Promotion
```

금지순서:
- Meaning before Identity
- Difference before Frame
- Relation before independent lock
- Causality before Snapshot
- Center before Closure
