# Method–Axis Relation Matrix

| 관계 | 의미 |
|---|---|
| SAME | 같은 Typed Layer·같은 Evidence |
| PARALLEL | 같은 축의 독립 검산 |
| PARTIALLY_INDEPENDENT | 공통층과 새 층이 함께 존재 |
| COMPLEMENTARY | 서로 다른 Blind Region 보완 |
| CONFLICTING | 동일 Typed Position에 양립불가능 결과 |
| META_FRAME | 다른 축을 배치하지만 Object-level 축은 아님 |

중요관계:

- AX-04→AX-05→AX-06→AX-07: Boundary→Function→Transition→Center
- AX-12→AX-14: Frame 이후 Difference
- AX-16 ⟂ AX-19 후대조: 형상과 의미 독립
- AX-20 ≠ Causality
- AX-15는 Authority를 높이지 않음
