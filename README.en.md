## Abstract

This paper is a foundational formulation for revealing the structure-formation process hidden inside what appears too obvious to notice.

Expressions such as `1+1=2`, `1/2+1/2=2/2`, `line+line=line`, and `field oplus field → fabric` are already familiar as results. However, the process by which such results are formed through the relation between existence-state and field-state has long remained compressed.

Previously, this line of thought was attached to Ctp theory and called `Ctp Obvious Theory`. At the present stage, however, the relation between existence and field can be explained directly through the structure-formation operation and the operator `oplus`, without requiring Ctp as the primary explanatory frame.

The structure-formation operation is not an arithmetic formula for calculating a result. It is a structural expression for showing how a formed state emerges through existence-state, criterion-field, relation-connection, and observation criterion.

The central expressions are:

```text
1/0 oplus 0/1 → 1/1
1 oplus 1 → 2
```

Here, `1/0` is an existence-state candidate, `0/1` is a criterion-field candidate, and `1/1` is a formed state in which existence is placed on a field. Likewise, `1 oplus 1 → 2` is not merely an arithmetic result. It expresses the process by which two already formed states enter relation within the same field and appear as the next formed state.

This paper does not attempt to replace mathematics or physics. It is a foundational paper of structure principle that makes visible the formation process that was already known but passed over as too obvious.

## 1. Problem Statement

People know `1+1=2` too easily.

Because this expression has been used for so long and accepted as obvious, the structure-formation process inside it is rarely questioned.

Standard arithmetic closes the result:

```text
1 + 1 = 2
```

Structure principle asks how that result is formed:

```text
1 oplus 1 → 2
```

The focus is not the value `2` itself. The focus is on the following questions:

```text
What state is 1?
Are the two 1s placed on the same field?
How do the two 1s connect?
Why does the result appear as 2?
Is 2 an end, or is it material for the next beginning?
```

The purpose is not to make an easy expression difficult. The purpose is to make visible the structure-formation process that had been compressed inside the simplest expression.

## 3. Separation of Existence and Field

In structure principle, existence and field are not read as already merged.

First, existence is separated.  
Then field is separated.  
Then the way in which the two states reconnect is examined.

```text
existence alone = 1/0
field alone     = 0/1
structure-connection of existence and field = 1/1
```

`1/0` is an existence-state candidate.  
It is the state in which something is present, but the criterion-field on which it can be placed has not yet been secured.

`0/1` is a criterion-field candidate.  
It is the state in which a field exists, but no existence has yet been placed on it.

`1/1` is the formed state in which existence is placed on the field.

Therefore, the central expression is:

```text
1/0 oplus 0/1 → 1/1
```

This expression is not an arithmetic equality.  
It marks the process by which an existence-state candidate and a criterion-field candidate structurally connect into a formed state.

## 4. oplus

`oplus` is not simple addition.

```text
oplus = O + plus
```

Here, `O` means a closed field, boundary, or criterion-field.  
`plus` means direction-opening, connection, or relation-opening.

Thus, `oplus` is defined as follows:

```text
oplus
= a structure-formation operator by which two states,
  while preserving their source boundaries,
  connect within a closed criterion-field
  and reveal a formed state
```

`A oplus B → C` is not `A+B=C`.

`A oplus B → C` means:

```text
A and B each have their own boundary.
The two states become relation-capable within the same field.
oplus marks the process of relation-connection.
As a result, C appears as a formed state.
```

Therefore, `=` and `→` are also separated.

```text
=  : closes result-equivalence
→  : marks formation, transition, and relation-progression
```

## 5. A Result Is Not an End

A result is not an end.

A result is a byproduct obtained through process, and it becomes the cause or material of the next beginning.

```text
process → result → source/material → next process
```

`1` also has this property.

```text
1
= once-formed state
= closed result-value
= minimal complete unit that can enter the next structure-formation operation
```

Therefore, the process by which `1` becomes `2` is not sufficiently expressed by the result alone.

```text
1 + 1 = 2
```

is a result-expression.

```text
1 oplus 1 → 2
```

is a structure-formation expression.

## 6. Denominators Cannot Be Added

Fractions make the separation between existence and field clearer.

```text
1/2 + 1/2 = 2/2
```

not:

```text
1/2 + 1/2 ≠ 2/4
```

The numerator is what is placed: existence-state or content.  
The denominator is the field on which it is placed: criterion-field, bowl, or matrix.

Therefore, when two `1/2` states connect within the same criterion-field, the numerators are added. The denominator is not an additive value. It is the shared field on which the two states are placed.

```text
1/2 oplus 1/2 → 2/2
```

`2/2` is the structural state, while `1` is the simplified result-value.

## 7. Line, Surface, and Fabric

Within the same dimension, adding line to line remains line.

```text
line + line = line
```

Adding surface to surface remains surface.

```text
surface + surface = surface
```

However, when lines enter relation within the field of a surface while preserving different directions, a surface can be formed.

```text
line/surface oplus line/surface → surface
```

The weaving structure of a loom demonstrates this.

```text
warp = vertical thread / vertical field
weft = horizontal thread / horizontal field
```

When vertical and horizontal lines cross and interweave, the result is not merely an increase in line. It is a woven surface.

```text
field oplus field → fabric
```

Fabric is not the simple sum of lines. Fabric is a relational field formed by different directional fields interweaving through oplus.

## 8. Light Is a Criterion-Field and Cannot Be Treated as an Operand

In ordinary velocity examples, the motion-state of existence and the motion-state of the field can be separated.

```text
existence m oplus field 0  → external observation m
existence m oplus field m  → external observation 2m
existence m oplus field -m → external observation 0
```

However, the speed of light cannot be treated as an ordinary motion value `m`.

Light appears as a single absolute value and functions as a criterion-field.  
Because light itself functions as a criterion-field, it cannot be placed simultaneously as an existence operand and as a field operand.

Therefore, the following expressions are not valid:

```text
c oplus c → c
c oplus c → 2c
```

The correct judgment is:

```text
c oplus c = OPERATION_CONDITION_NOT_FORMED
```

Light is not a value added by oplus. It functions as a criterion-field that determines whether the oplus operation is formable.

## 9. Natural Field and Theoretical Field

All fields can be broadly separated into natural fields and theoretical fields.

```text
natural field = field made by nature
theoretical field = field made by humans
```

A natural field existed before humans.  
Cosmic fields, material fields, force fields, life fields, and time-space fields belong to natural field.

A theoretical field is made by humans when they observe natural fields and natural materials and organize them through language, mathematics, rules, institutions, models, and hypotheses.

Many fields made by humans are formed by the connection of natural field and theoretical field.

```text
natural field oplus theoretical field → human-made application field
```
