## 5. oplus guard

`oplus` is not simple addition.

```text
oplus = O + plus

O = closed field / boundary / criterion field
plus = direction-opening / connection / relation-opening
```

`A oplus B → C` means:

```text
A and B preserve their source boundaries.
A and B become relation-capable within a field.
The relation-connection process is marked by oplus.
C appears as a formed state.
```

Do not read `oplus` as ordinary `+`.

```text
+  = ordinary addition or direction marker
=  = result-equivalence closure
→  = formation / transition / relation progression
oplus = structure-formation relation operation
```
