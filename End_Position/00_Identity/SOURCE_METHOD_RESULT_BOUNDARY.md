# Source–Method–Result Boundary

```text
Source
≠ Method
≠ Result
```

- `Start_Position` Source는 구조원형의 Canonical Owner 후보다.
- `Center_Position`은 분석기법의 Canonical Owner다.
- `End_Position`은 Source-bound 분석결과의 Canonical Owner다.
- Exact Source Snapshot은 Result 재현용이며 새 Source 정본이 아니다.
- End의 Feedback은 승인 전 Start·Center Mutation이 아니다.
