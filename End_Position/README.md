# End_Position

`End_Position`은 특정 Source에 `Center_Position`의 분석기법·진행과정·분석재료를 적용하여 형성한 Source-bound Result를 보존한다.

## Result 001

이번 첫 결과는 다음 질문을 검산한다.

> 글자 자체를 구조도형으로 파자해 얻은 구조원형이 사용자의 평면·공간도형 생성순서로 이어지고, 도형에서 다시 관계문법으로 역복원될 수 있는가?

## 최종 답

```text
글자구조
→ 도형구조로 이어질 수 있음

이어지는 것
→ exact 글자 Carrier가 아니라 최소 관계문법

도형이 추가하는 것
→ 계량·깊이·면·투영·교차·대칭

도형에서 되찾을 수 있는 것
→ 관계문법

도형에서 단독으로 되찾을 수 없는 것
→ exact 글자 Identity·유일한 공간 Object·실제 생성계보
```
