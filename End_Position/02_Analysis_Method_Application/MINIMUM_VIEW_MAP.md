# Minimum View Map

| 문제 | 최소 View |
|---|---|
| 글자구조 추출 | 원본 + 구조 파자 + 재조립·역복원 |
| 의미 비교 | 위 세 View + 의미·음가·기능 후대조 |
| 글자→도형 | 원본 + 구조 파자 + 도형전개 + 역복원 |
| 평면→공간 | 화면 + 깊이표지 또는 두 번째 투영 |
| 공간 Object 구분 | 화면 + Incidence 또는 Face View |
| 양방향 전체계보 | 원본 + 파자 + 도형전개 + 공간 Lift + 역복원 |
| 역사발생 주장 | 위 View + 외부 Source |
