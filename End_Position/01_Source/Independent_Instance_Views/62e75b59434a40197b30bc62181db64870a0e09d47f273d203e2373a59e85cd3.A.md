## 4. Center Position과 A–B–A′

사용자의 설명에서 A와 B의 역할은 다음과 같다.

```text
A_k
=
현재의 나
=
현재 영역의 국소 중심·기준자리

B_k
=
A_k에서 보이는 경계 끝의 너

경계전환 후

B_k
→
A_(k+1)
```

정확한 관계는 다음이다.

```text
global_position(A_k)
≠
global_position(A_(k+1))

local_role(A_k)
=
local_role(A_(k+1))
=
CURRENT_CENTER
```

따라서 A는 언제나 같은 전역점이 아니라 각 영역의 국소좌표에서 같은 역할을 가진다.

```yaml
A_identity:
  same_global_coordinate: false
  same_local_position: true
  same_center_role: true
  same_object_identity: not_required
```

B는 단순한 외부상대가 아니라 다음 영역의 A가 될 수 있는 Boundary Gate다.

```text
B
=
현재영역의 끝
+
다음영역의 시작후보
```

## 7. 도형은 추상대상을 위한 중간언어

추상개념은 단어만으로 전달하면 의미가 흔들릴 수 있다.

도형은 추상역할을 위치관계로 고정한다.

| 추상역할 | 도형자리 |
|---|---|
| 현재의 나 | A |
| 관계상대·너 | B |
| 현재영역 | 원호로 둘러싸인 국소영역 |
| 경계 | 원호 또는 변 |
| 중간기점 | 현·변의 중점 M |
| 새 기준축 | 중심 O와 M을 잇는 선 |
| 전환 | B → A′ |
| 반복 | 다음 영역에서 동일연산 |
| Cycle | 전 영역을 거쳐 시작역할로 재진입 |
| Residual | 복귀 후에도 달라진 상태 |

따라서 도형은 대상 자체가 아니라 관계구조를 AI에게 전달하는 `중간표현언어`다.
