## 6. A·B·A′와 바닥

```yaml
region_k:
  A_k:
    role: current_self_start_position
    label: 나
  B_k:
    role: terminal_other_position_seen_from_A
    label: 너
  floor_k:
    role:
      - current_region_boundary
      - end_start_conversion_gate
  center:
    role:
      - local_reference
      - coordinate_regeneration_position
```

관계후보:

```text
A_k → B_k | T_boundary → A_(k+1)
```

비동일성:

```text
B_k
≠ A_(k+1) as absolute object
```

하지만 역할전환은 가능하다.

```text
End-role(B_k)
→ boundary transition
→ Start-role(A_(k+1))
```

따라서 `너`는 다른 존재일 수도 있고, 같은 Identity의 다른 시간·영역·관측상태일 수도 있다.

```text
same existence
≠ same position

different position
≠ different existence
```
