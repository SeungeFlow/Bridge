## 3.2 정육면체 몸대각선 투영 Lift

### 구성

정육면체를 서로 반대인 두 꼭짓점을 잇는 몸대각선 방향에서 본다.

```text
가까운 몸대각선 끝꼭짓점
+
먼 몸대각선 끝꼭짓점
→
평면의 같은 중심위치로 투영

나머지 여섯 꼭짓점
→
외곽 정육각경계의 여섯 기점
```

### 모서리 관계

정육면체의 모서리는 모두 열두 개다.

투영하면:

```text
여섯 모서리
→ 외곽 육각경계

가까운 중심꼭짓점의 세 모서리
→ 교대로 놓인 외곽기점 세 곳

먼 중심꼭짓점의 세 모서리
→ 나머지 외곽기점 세 곳
```

평면에서는 두 중심꼭짓점이 겹치므로 결과적으로 여섯 방사선처럼 보인다.

### 필수 깊이복원

```text
평면의 한 중심점
→ 공간의 두 반대꼭짓점으로 분리

여섯 방사선
→ 두 중심꼭짓점에 교대로 귀속
```

이 분리가 없으면 그림은 하나의 허브가 여섯 꼭짓점에 연결된 Wheel Graph일 뿐이며 정육면체 Graph가 아니다.

### 핵심원리 결속

```text
같은 평면위치
≠ 같은 공간점
≠ 같은 Object Identity
```

이는 이번 프로젝트의:

```text
같은 좌표
≠ 같은 역할
```

을 한 단계 확장한다.

### 면 오독 방지

평면에 보이는 여섯 삼각구역을 정육면체의 여섯 면이라고 읽으면 안 된다.

```text
평면 삼각구역
≠ 실제 정사각면
```

정육면체의 각 정사각면은 투영에서 중심과 여러 외곽기점을 포함하는 사변형 영역으로 겹쳐 보인다.
