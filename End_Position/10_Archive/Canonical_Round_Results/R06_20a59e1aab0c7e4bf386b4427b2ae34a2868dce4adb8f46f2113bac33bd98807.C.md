# 2. 정육면체 Lift의 역투영

## 2.1 공간 Object

```yaml
cube_vertices: 8
cube_edges: 12
view_direction: body_diagonal
```

## 2.2 평면 Rendering

몸대각선 방향으로 투영하면:

```yaml
spatial_vertices: 8
visible_screen_positions: 7
spatial_vertices_at_screen_center: 2
peripheral_screen_positions: 6
visible_simple_edges: 12
```

두 반대꼭짓점은 같은 화면 중심위치로 겹친다.

나머지 여섯 꼭짓점은 외곽 정육각 위치를 만든다.

## 2.3 Graph 검산

투영 후 화면에서 보이는 단순 연결 Graph는:

```text
외곽 여섯 기점의 순환경계
+
화면 중심과 여섯 외곽기점의 방사연결
```

이다.

기계판정:

```yaml
cube_projection_equals_six_spoke_wheel_graph: true
visible_vertices: 7
visible_edges: 12
```

## 2.4 역복원에 필요한 추가정보

화면 Wheel Graph에서 정육면체를 복원하려면 다음을 추가해야 한다.

```text
화면 중심위치
→ 가까운 공간꼭짓점
+ 먼 공간꼭짓점

여섯 방사선
→ 두 공간꼭짓점에 교대로 귀속

외곽 여섯 변
→ 정육면체의 나머지 모서리

화면의 삼각구역
→ 실제 면이 아니라 투영 Sector
```

추가정보가 없으면:

```text
Wheel Graph
→ 정육면체
```

는 유일 역복원이 아니다.

```yaml

```

따라서:

```text

≠ 자동으로 엄밀한 Fractal
```

이다.
