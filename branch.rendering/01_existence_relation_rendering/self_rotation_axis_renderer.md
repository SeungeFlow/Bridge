# self_rotation_axis_renderer.md

## purpose

Displays existence-side self-rotation axis and local coordinate frame.

```text
parent_global_frame ≠ child_local_frame
Z_G ≠ z_c
```

Parent/global frame is locked. Child/local frame is attached to the existence or mass body. If tilted, local axes remain mutually perpendicular and rotate together as one local frame.
