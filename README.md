## 현재 상태

```yaml
completed_rounds: R00-R09
next_round: R10
package_state: CANONICAL_UPLOAD_CANDIDATE_SEALED
github_upload: NOT_EXECUTED
independent_reapplication: READY_NOT_EXECUTED
center_status: CANDIDATE_NOT_CONFIRMED
```
