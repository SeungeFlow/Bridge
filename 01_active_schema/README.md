# Active_Schema Bridge Theory Projection

이 Directory는 Zenodo Active_Schema Package 자체가 아니다.

이 Directory는 Active_Schema Version 1.0.0의 Bridge Theory Projection이다.

Canonical Package는 다음 Publication Identity와 Package Identity로 식별한다.

```yaml
version_doi: 10.5281/zenodo.21410576
package_sha256: 42bb7089e5cdfb52eb951b3bb53613c7ed75168337c2a76524a0e47b5eefb88c
manifest_digest: 5d1565212ef510ffe5576dc80449d928c0b1bfbe05cce24e12ee4426bbd18353
schema_version: "1.0.0"
```

Genesis Binding의 정본은 `SeungeFlow/Relation`의
`05_hash_relation_track_registry/`에 생성된다.

## Projection content

1. `ROOT_CONTRACT.md` — Exact Byte Copy
2. `THEORY.md` — Exact Byte Copy
3. `NON_CLAIMS.md` — Exact Byte Copy
4. `position.yaml` — Exact Byte Copy
5. `restart.yaml` — Exact Byte Copy
6. `ACTIVE_SCHEMA_PUBLICATION_REFERENCE.yaml` — Generated Projection

`before_position`은 변경하거나 재귀적으로 복제하지 않는다.
