## 2. C=(m,t,p,?) Decomposition

```text
C = (m,t,p,?)
```

### m

이 문서에서 `m`은 물리학의 mass로 바로 닫지 않는다.

```text
m
= 숫자화 가능한 관측대상
+ 데이터값을 가진 상태
+ 양과 질이 결속되어 질량상태가 될 수 있는 후보
```

더 세분하면:

```text
q = 양 / 절대값 / 존재가 가진 raw quantity
κ = 질 / 결속력 / 응축도 / 관계밀도
m* = q oplus κ 로 형성된 질량상태
```

### t

```text
t
= 전이상태
+ phase
+ recurrence
+ 상태변화 시간
```

물에서는 `얼음 → 물 → 수증기` 전이가 된다.  
공기에서는 `압력차 → 바람` 전이가 된다.  
빛에서는 `도달 / 반사 / 굴절 / 밝기 변화`의 전이가 된다.  
에너지에서는 `상태변화 가능성`이 전이조건으로 작동한다.

### p

```text
p
= 놓인 자리
+ field coordinate
+ 관측 위치
+ 기준장 내부의 상태좌표
```

물의 p는 온도, 압력, 용기, 위치가 된다.  
공기의 p는 압력장, 공간, 밀도, 온도장이 된다.  
빛의 p는 매질, 방향, 거리, 관측면이 된다.  
에너지의 p는 전이가 일어나는 field이다.

### ?

```text
?
= boundary
+ definition
+ condition
+ observer
+ criterion
+ target
+ self-question gateway
```

이 문서에서 `?`는 특히 다음을 묻는다.

```text
무엇을 양으로 볼 것인가?
무엇을 질로 볼 것인가?
무엇을 질량으로 볼 것인가?
분자는 무게인가, 부피장인가?
분모는 기준장인가, 부피장인가?
빛은 피연산자인가, 관측기준인가?
에너지는 물질인가, 전이조건인가?
```

## 5. Water Example

과학적 source fact:

```text
물 = H₂O
```

구조해석:

```text
H₂O의 절대량 = q
결속력 / 밀도 / 상태 / 분자관계 = κ
q oplus κ → 물의 질량상태 m*
```

액체 물을 기준장으로 둔다.

```text
액체 물 = 1/1
```

단, 분자와 분모를 먼저 고정해야 한다.

### 밀도식 표기

```text
분자 = 같은 물질량 / 무게 / H₂O 양
분모 = 그 물질량이 차지하는 부피장
```

그러면:

```text
액체 물 = 1/1
얼음 = 1/1.09
수증기 = 1/N
```

### 부피장 초과 표기

```text
분자 = 차지한 부피장
분모 = 물 기준장
```

그러면:

```text
액체 물 = 1/1
얼음 = 1.09/1
수증기 = N/1
```

둘 다 가능하지만, 반드시 `?`가 먼저 분자와 분모의 의미를 고정해야 한다.

## 9. Relation to Ctp24_0033 — C=tp × F=ma Swap Matrix Cross Check

`Ctp24_0043`은 갑자기 새로 나온 문서가 아니다.  
그 이전에 `Ctp24_0033_ctp_fma_swap_matrix_cross_check.md`에서 이미 `C=tp`와 `F=ma`를 교차시켜 구조검산을 시도한 흔적이 있다.

```text
Ctp24_0033
= C=tp 와 F=ma 를 나란히 놓고
  스왑행렬로 교차검산하여
  C=am 가능성을 연 선행 문서
```

기본 배치는 다음과 같다.

```text
C = t p
F = m a
```

이를 구조판에 놓으면:

```text
C   t   p
F   m   a
```

처음 대응은 다음처럼 보인다.

```text
t ↔ m
p ↔ a
```

그러나 `Ctp24_0033`의 핵심은 이 대응을 그대로 고정하지 않고, 스왑하여 다음 관계를 읽은 것이다.

```text
t ↔ a
p ↔ m
```

이 스왑에서 중요한 점은 다음이다.

```text
t ↔ a
= 시간은 단순 흐름이 아니라
  가속된 전이상태로 읽힐 수 있다.

p ↔ m
= 질량은 단순 물리량이 아니라
  어떤 자리에 놓인 대상 / field coordinate에 배치된 상태로 읽힐 수 있다.
```

그 결과 `C=am` 구조가 열린다.

```text
C = a m
```

또는:

```text
C = a × m
```

여기서 `C`는 단순 계산값이 아니다.

```text
C
= 가속된 전이 a와
  놓인 대상 m이
  관계하여 결정화된 상태
```

즉 `C=am`은 `C=tp`를 버린 것이 아니라, `C=tp`와 `F=ma`를 같은 구조판에 놓고 교차검산했을 때 드러난 관계식이다.
