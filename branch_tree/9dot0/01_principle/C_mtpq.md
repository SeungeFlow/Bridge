# C=(m,t,p,?)

C=(m,t,p,?) is a structure placement formula.

m:
  existent / object / relation-bearing unit

t:
  transition / difference / direction change / distance gap

p:
  place / position / field

?:
  observation criterion / boundary question / pre-definition

Definition direction:
  ? -> p -> t -> m -> C

Formation direction:
  m -> t -> p -> C
