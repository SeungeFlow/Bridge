# vocab.branch source policy

## source hierarchy

Repo.SeungeFlow is the source-field.

Repo.9Dot0 is the structure-realization field.

vocab.branch reads both through README vocab and Raw URL source identity.

## source identity fields

A source unit should keep:

- repo
- branch
- commit hash
- path
- Raw URL
- source status
- file role

## baseline rule

README.md files define baseline vocab.

If a term is missing from README.md, update the relevant README.md first.
