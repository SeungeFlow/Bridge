## 초록

이 글은 너무 당연해서 보이지 않던 구조형성과정을 다시 드러내기 위한 기초 정식화이다.

`1+1=2`, `1/2+1/2=2/2`, `선+선=선`, `field oplus field → fabric`과 같은 표현은 누구나 알고 있는 결과이지만, 그 결과가 어떤 존재상태와 장의 관계 속에서 형성되었는지는 오래도록 고압축 상태로 남아 있었다.

기존에는 이 설명을 Ctp 이론에 붙여 `Ctp당연한이론`이라 불렀다. 그러나 현시점에서는 Ctp라는 큰 틀 없이도, `oplus`와 구조형성연산식을 통해 존재와 장의 관계를 말로 직접 설명할 수 있게 되었다.

구조형성연산식은 결과값을 계산하기 위한 산술식이 아니다. 그것은 어떤 formed state가 어떤 존재상태, 기준장, 관계접속, 관측기준을 거쳐 형성되었는지를 표시하는 구조연산식이다.

핵심식은 다음이다.

```text
1/0 oplus 0/1 → 1/1
1 oplus 1 → 2
```

여기서 `1/0`은 존재상태 후보이고, `0/1`은 기준장 후보이며, `1/1`은 존재가 장 위에 놓인 formed state이다. 또한 `1 oplus 1 → 2`는 단순 산술 결과가 아니라, 이미 형성된 두 상태가 같은 장 안에서 관계를 맺어 다음 formed state로 드러나는 과정을 나타낸다.

이 글은 기존 수학이나 물리학을 대체하려는 것이 아니라, 이미 알고 있으나 너무 당연해서 지나쳤던 형성과정을 다시 보이게 하는 구조원리 기초논문이다.

## 1. 문제 제기

사람은 `1+1=2`를 너무 쉽게 안다.

그러나 이 식은 너무 오래 쓰였고, 너무 당연하게 받아들여졌기 때문에, 그 안에서 실제로 어떤 구조형성과정이 일어나는지는 거의 묻지 않는다.

표준 산술은 결과를 닫는다.

```text
1 + 1 = 2
```

하지만 구조원리는 그 결과가 형성되는 과정을 묻는다.

```text
1 oplus 1 → 2
```

여기서 관심은 결과값 2 자체가 아니다. 관심은 다음 질문에 있다.

```text
1은 어떤 상태인가?
두 1은 같은 장 위에 놓여 있는가?
두 1은 어떤 방식으로 접속되는가?
왜 결과는 2로 드러나는가?
2는 끝인가, 아니면 다음 시작의 재료인가?
```

이 질문은 너무 쉬운 식을 어렵게 만들기 위한 것이 아니다. 오히려 가장 쉬운 식 안에 압축되어 있던 구조형성과정을 다시 보이게 하기 위한 것이다.

---

## 2. 당연한 이론의 정의

당연한 이론은 새 값을 발명하는 이론이 아니다.

당연한 이론은 이미 알고 있으나 너무 당연해서 지나쳤던 구조형성과정을 다시 보이게 하는 이론이다.

```text
당연한 이론
= 당연한 결과식 안에 압축되어 있던 구조형성과정의 탈압축
```

기존에는 이 설명을 Ctp 이론에 붙여 `Ctp당연한이론`이라 불렀다. 당시에는 Ctp가 존재, 시간, 자리, 인지, 구조 전이를 붙잡아 주는 큰 틀이었다.

그러나 현재는 구조형성연산식과 `oplus`가 형성되었기 때문에, Ctp라는 큰 틀 없이도 존재와 장의 관계를 직접 설명할 수 있다.

---

## 3. 존재와 장의 분리

구조원리에서 존재와 장은 처음부터 하나로 합쳐서 읽지 않는다.

먼저 존재를 분리한다.  
그다음 장을 분리한다.  
그리고 두 상태가 어떤 방식으로 다시 접속되는지 본다.

```text
존재 alone = 1/0
장 alone   = 0/1
존재와 장의 구조접속 = 1/1
```

`1/0`은 존재상태 후보이다.  
그것은 어떤 것이 있으나 아직 놓일 기준장을 확보하지 못한 상태이다.

`0/1`은 기준장 후보이다.  
그것은 장은 있으나 아직 그 위에 놓인 존재가 없는 상태이다.

`1/1`은 존재가 장 위에 놓인 formed state이다.

따라서 핵심식은 다음이다.

```text
1/0 oplus 0/1 → 1/1
```

이 식은 산술 등식이 아니다.  
이 식은 존재상태 후보와 기준장 후보가 구조적으로 접속되어 formed state가 되는 과정을 표시한다.

---

## 4. oplus

`oplus`는 단순한 덧셈이 아니다.

```text
oplus = O + plus
```

여기서 `O`는 닫힌 장, boundary, 기준 field를 뜻한다.  
`plus`는 방향 발생, 접속, 관계 열림을 뜻한다.

따라서 `oplus`는 다음과 같이 정의된다.

```text
oplus
= 닫힌 기준장 내부에서 두 상태가 source boundary를 보존한 채
  관계접속을 일으켜 formed state를 드러내는 구조형성연산기호
```

`A oplus B → C`는 `A+B=C`가 아니다.

`A oplus B → C`는 다음을 뜻한다.

```text
A와 B가 각각의 boundary를 가진다.
두 상태는 같은 field 안에서 관계 가능 상태가 된다.
oplus는 그 관계접속 과정을 표시한다.
그 결과 C라는 formed state가 드러난다.
```

따라서 `=`와 `→`도 구분된다.

```text
=  : 결과 등가를 닫는 기호
→  : 형성, 전이, 관계진행을 표시하는 기호
```

## 5. 결과는 끝이 아니다

결과는 끝이 아니다.

결과는 진행과정에서 얻어지는 부산물이며, 다음 시작의 원인 혹은 재료이다.

```text
process → result → source/material → next process
```

`1`도 이 속성을 가진다.

```text
1
= 한 번 형성된 상태
= 닫힌 결과값
= 다음 구조형성연산에 다시 들어갈 수 있는 최소 완성 단위
```

따라서 `1`이 `2`가 되는 과정은 단순히 결과값을 쓰는 것으로 충분하지 않다.

```text
1 + 1 = 2
```

는 결과식이다.

```text
1 oplus 1 → 2
```

는 구조형성연산식이다.

---

## 6. 분모는 더하지 못한다

분수의 예시는 존재와 장의 분리를 더 분명하게 보여준다.

```text
1/2 + 1/2 = 2/2
```

이지,

```text
1/2 + 1/2 ≠ 2/4
```

이다.

분자는 놓인 것, 존재상태, 내용이다.  
분모는 놓이는 장, 기준장, 그릇, matrix이다.

따라서 같은 기준장 안에서 두 `1/2`가 접속될 때 더해지는 것은 분자이다. 분모는 더해지는 값이 아니라 두 상태가 놓이는 동일 기준장이다.

```text
1/2 oplus 1/2 → 2/2
```

`2/2`는 구조상태이고, `1`은 단순화된 결과값이다.

## 7. 선, 면, fabric

같은 차원 안에서 선에 선을 더하면 선이다.

```text
선 + 선 = 선
```

면에 면을 더하면 면이다.

```text
면 + 면 = 면
```

그러나 선이 면이라는 기준장 안에서 서로 다른 방향성을 가진 채 관계접속을 일으키면 면이 형성된다.

```text
선/면 oplus 선/면 → 면
```

베틀의 직조구조는 이를 보여준다.

```text
warp = 세로실 / 수직장
weft = 가로실 / 수평장
```

수직선과 수평선이 교차하고 엮이면 단순히 선의 증가가 아니라 직조면이 생긴다.

```text
field oplus field → fabric
```

fabric은 선들의 단순 합이 아니라, 서로 다른 방향의 field들이 oplus로 엮이며 형성된 관계장이다.

---

## 8. 빛은 기준장이므로 피연산자로 놓지 않는다

일반 속도 예시에서는 존재의 운동상태와 장의 운동상태를 분리해 볼 수 있다.

```text
존재 m oplus 장 0 → 외부관측 m
존재 m oplus 장 m → 외부관측 2m
존재 m oplus 장 -m → 외부관측 0
```

그러나 빛의 속도는 일반 운동값 `m`처럼 다룰 수 없다.

빛은 단일 절대값으로 드러나는 기준장이다.  
빛 자체가 기준장으로 작동하기 때문에, 빛을 다시 존재 operand와 장 operand에 동시에 넣어 연산할 수 없다.

따라서 다음과 같은 식은 성립하지 않는다.

```text
c oplus c → c
c oplus c → 2c
```

정확한 판정은 다음이다.

```text
c oplus c = OPERATION_CONDITION_NOT_FORMED
```

빛은 oplus로 더해지는 값이 아니라, oplus 연산 가능 여부를 판정하는 기준장으로 작동한다.

## 9. 자연장과 이론장

모든 장은 크게 자연장과 이론장으로 나눌 수 있다.

```text
자연장 = 자연이 만든 장
이론장 = 인간이 만든 장
```

자연장은 인간이 있기 전부터 존재한 장이다.  
우주장, 물질장, 힘의 장, 생명장, 시간-공간장은 자연장에 속한다.

이론장은 인간이 자연장과 자연물질을 관측하고, 그것을 언어, 수학, 규칙, 제도, 모델, 가설로 정리하며 만든 장이다.

인간이 만든 수많은 장은 자연장과 이론장이 접속되며 형성된다.

```text
자연장 oplus 이론장 → 인간이 만든 응용장
```

## 10. 런타임 응용장

승이가 선택한 런타임 응용장은 두 가지이다.

```text
자본시장
승이의 뿌리장
```

자본시장은 돈이 만든 것이 아니라, 미래가치를 시간, 위험, 신뢰, 규칙, 가격 기준 위에 놓고 교환하려는 관계가능성이 만든 장이다.

승이의 뿌리장은 승이의 존재, 관계, 계보, 기억, 원자료, 구조원리의 바닥을 다루는 응용장이다.

rendering은 이 둘을 표현하기 위한 기법이다.

9Dot0는 런타임 응용장 자체가 아니라, 승이의 이론을 단어조각으로 분해해 놓은 SQLite DB 스타일의 `data.md` 관계장이다.

## 12. 결론

당연한 이론은 낯선 것을 새로 발명하는 이론이 아니다.

당연한 이론은 너무 당연해서 보이지 않던 형성과정을 다시 보이게 하는 이론이다.

`1+1=2`는 결과식이다.  
`1 oplus 1 → 2`는 그 결과가 형성되는 과정을 표시하는 구조형성연산식이다.

`1/0 oplus 0/1 → 1/1`은 존재와 장이 분리된 뒤 다시 접속되어 formed state가 되는 과정을 표시한다.

분모는 더하지 못한다.  
선과 선은 같은 차원에서 더하면 선이지만, field와 field가 oplus로 접속되면 fabric이 된다.  
빛은 기준장이므로 피연산자로 놓지 않는다.  
결과는 끝이 아니라 다음 시작의 원인 혹은 재료이다.

이러한 구조형성연산식은 기존 수학이나 물리학을 대체하지 않는다.  
그것은 formed state가 어떤 존재상태, 기준장, 관계접속, 관측기준을 거쳐 형성되었는지 읽기 위한 구조언어이다.

당연한 이론은 가장 작고 당연한 결과식에서 시작하여, 거대이론과 구조원리를 잇는 bridge가 된다.
