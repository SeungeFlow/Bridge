# rendering_of_renderer_plan.md

## purpose

Plans how the two rendering branches lower toward Repo.9Dot0 Runtime candidates.

Rendering of renderer means defining what a renderer should show, what it must not merge, and how its output must return to source/schema.

Target is not direct execution. Target is Runtime of Active_Schema candidate.
