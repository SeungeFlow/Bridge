# field_relation_definition.md

## core definition

Field is not empty background. Field is a relation-region with matrix / bowl / container conditions.

```text
field = matrix = container = denominator = bowl = 담는 것
existence/content = grid = numerator = water = 담길 것
```

Field identity includes center, six directions, integer radius, XY/XZ/YZ planes, center-balance criterion point, matrix/container condition.

Field identity is preserved. Runtime state and visibility may change.
