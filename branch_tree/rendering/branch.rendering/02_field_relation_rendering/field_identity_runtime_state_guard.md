# field_identity_runtime_state_guard.md

## core guard

```text
field_identity ≠ runtime_state
```

Field identity:

```text
matrix/container condition
center
six directions
integer radius
XY/XZ/YZ planes
center-balance criterion point
```

Runtime state:

```text
existence position
self_rotation
orbit
observed frame
visibility state
tilted local frame relation
```
