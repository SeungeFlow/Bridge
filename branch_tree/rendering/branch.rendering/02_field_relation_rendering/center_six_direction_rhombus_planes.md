# center_six_direction_rhombus_planes.md

## core structure

```text
center → six directions → endpoints → rhombus planes → center-balance criterion point
```

Directions:

```text
+ direction: right / front / up
- direction: left / back / down
```

Axes:

```text
X = width +/-
Y = depth +/-
Z = height +/-
```

Planes:

```text
XY = equator dividing plane
XZ = visible vertical relation plane candidate
YZ = hidden-but-existing plane
```

```text
XY × XZ × YZ → center_balance_criterion_point
```
