# hidden_plane_visibility_renderer.md

## proposition

```text
visibility ≠ existence
hidden ≠ nonexistent
```

YZ plane is usually unseen but exists. Renderer must preserve it as a layer, label, dashed/transparent surface, or metadata.

Plane identity and visibility state are separate.
