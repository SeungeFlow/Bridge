# reference_plane_and_tilt_renderer.md

## proposition

A larger mass-field or larger relation-field may be selected as reference field. This does not make it an absolute plane.

```text
reference_plane ≠ absolute_plane
tilt ≠ absolute_property
```

Parent/global frame is locked. Child/local frame belongs to the smaller mass body and is tilted relative to the parent frame.

Required fields: reference_plane, reference_plane_owner, parent_global_frame, child_tilted_local_frame, tilt_angle, rotation_axis_or_hinge, x_axis_mode, observed_frame, visibility_state.
