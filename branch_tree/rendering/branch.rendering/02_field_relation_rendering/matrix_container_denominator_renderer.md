# matrix_container_denominator_renderer.md

## source mapping

```text
BD = matrix = denominator = bowl = container = 담는 것
AC = grid = numerator = water = content = 담길 것
```

Denominator is not merely a lower number. It is the container condition.

Capacity rule:

```text
denominator_capacity >= numerator_content
```

Examples:

```text
5/10 = contained with remaining field
10/10 = full match, no margin
10/5 = arithmetic value exists, structural containment fails
```
