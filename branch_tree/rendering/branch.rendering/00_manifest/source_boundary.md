# source_boundary.md

## purpose

Defines the boundary between source, memo, derived schema, renderer candidate, and Runtime candidate.

```text
S0: Repo.SeungeFlow higher source layer
S1: USER_ORGANIZED_MD_SOURCE = 관계의 정의와 구조원리(4).md
S2: WATER_BOWL_FRACTION_MEMO_SOURCE = 물과그릇.txt
S3: gpt.system derived schema layer
S4: renderer_v0_1 local draft tool candidate
S5: Repo.9Dot0 Runtime candidate layer
```

Hard rule:

```text
S0 ≠ S1 ≠ S2 ≠ S3 ≠ S4 ≠ S5
```

S1 provides field relation material: exponent/state expansion, center, six directions, X/Y/Z, XY/XZ/YZ rhombus planes, center-balance criterion point, scalar table.

S2 provides water/bowl fraction memo:

```text
AC = grid / numerator / water / content
BD = matrix / denominator / bowl / container
```
