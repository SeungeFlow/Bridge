# reverse_check.md

## purpose

Checks that existence-rendering surface returns to source relation definition.

Return path:

```text
surface
→ source expression
→ existence identity
→ grid/content/numerator/water role
→ field boundary reference
→ capacity relation candidate
→ self_rotation state
→ internal endpoint
→ dot crossing
→ external starting point
→ source boundary
```
