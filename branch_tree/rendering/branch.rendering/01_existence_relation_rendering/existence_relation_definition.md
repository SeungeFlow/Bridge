# existence_relation_definition.md

## core definition

Existence is a relation-bearing unit. It can be placed, can carry a state, can be contained by a field, can have self-rotation/orientation, and can cross dot from internal endpoint to external starting point.

```text
existence = relation-bearing unit = grid / content / numerator / water = 담길 것
field = matrix / container / denominator / bowl = 담는 것
```

Existence is not field. A formed field can become existence candidate only in a declared next layer.
