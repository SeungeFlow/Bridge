# dot_crossing_endpoint_renderer.md

## core structure

```text
internal endpoint → dot → external starting point
```

```text
endpoint = prior layer internal endpoint
dot = critical-between transition point
0 = open empty state after dot
1 = minimum occupied pin
external starting point = new start after crossing
```

`9dot0` is not numeric 9.0. Dot is not decimal point and dot is not 0.
